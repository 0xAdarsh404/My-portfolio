# Adarsh Pratap Singh - Portfolio

A modern, responsive personal portfolio website built with React, Bootstrap, and custom CSS, showcasing my skills, projects, experience, and education.

## 🌐 Live Demo

Check out the live site: [https://adarsh-pratap-singh-portfolio.netlify.app/](https://adarsh-pratap-singh-portfolio.netlify.app/)

## 🚀 Features

- **Responsive Design**: Works perfectly on mobile, tablet, and desktop
- **Dark/Light Theme**: Toggle between themes
- **Animated UI**: Smooth animations and transitions
- **Sections**: Home, About, Skills, Projects, Education, Contact
- **Interactive Elements**: Hover effects, button animations, typing effect

## 🛠️ Tech Stack

- **React 18.2.0** - UI library
- **React Bootstrap 2.8.0** - UI components
- **React Icons 4.10.1** - Icon library
- **CSS3** - Custom styling with animations
- **Netlify** - Deployment

## 📂 Sections

1. **Home**: Hero section with name, title, contact info, and social links
2. **About**: Professional summary, highlights, and stats
3. **Skills**: Technical skills with progress bars and core cybersecurity knowledge
4. **Projects**: Showcase of key projects with descriptions and features
5. **Experience**: Professional experience details
6. **Education**: Academic background and certifications
7. **Contact**: Contact form and info

## 📦 Installation & Setup

To run the project locally:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/0xAdarsh404/My-portfolio.git
   cd My-portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm start
   ```

4. **Open in browser**:
   The app will be available at `http://localhost:3000`
